# lua-log-analyzer

Высокопроизводительный аналитический парсер лог-файлов на Lua 5.4.

## Возможности
- Разбор Nginx/Apache формата Combined Log Format через регулярные выражения Lua.
- Агрегация и статистика:
  - Топ запрашиваемых URL и эндпоинтов.
  - Распределение кодов статуса HTTP (2xx Успех, 3xx Редиректы, 4xx Клиентские ошибки, 5xx Ошибки сервера).
  - Топ уникальных IP-адресов посетителей.
  - Подсчет общего сетевого трафика в мегабайтах.
- Встроенный тестовый лог-файл `sample_access.log`.

## Сборка байт-кода
```bash
luac -o releases/analyzer.luac analyzer.lua
```

## Использование
```bash
# Анализ лог-файла
lua analyzer.lua sample_access.log

# Быстрый запуск из releases:
./releases/lua-log-analyzer.bat
```
